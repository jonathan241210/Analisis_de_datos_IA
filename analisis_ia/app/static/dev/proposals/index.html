Qué falta aún (no implementado)

Comparé el producto actual con Julius, Hex y cuadernos tipo Observable / DataPlay. Esto es un informe, no un plan de trabajo: nada de esta lista se ha construido. Elige qué entra al siguiente slice.

  1. Fuentes vivas SQL real (Postgres / MySQL / warehouses), Google Sheets y Drive. Hoy el formulario de BD responde 501 y solo hay CSV/TSV/Excel.
  2. Más formatos JSON, Parquet, PDF tabular, URLs y datasets de ejemplo empaquetados. Julius ya acepta PDF y Sheets.
  3. Visualización más rica Scatter, series temporales, violin, pairplot, mapas. Ahora: histograma, boxplot y correlación.
  4. Estadística inferencial t-test, chi-cuadrado, ANOVA y tests de normalidad, no solo descriptivos.
  5. Operaciones de outliers y joins Tratar extremos (winsor, recorte) y unir varios archivos. El agente detecta outliers; no hay botón para tratarlos ni fusionar tablas.
  6. Pipeline reproducible Exportar el historial de limpieza como script / notebook reejecutable (el fuerte de Julius y Hex).
  7. ML de verdad de producto Validación cruzada, predicción sobre filas nuevas, persistir el modelo, forecasting. Hoy se entrena en sesión y se pierde.
  8. Memoria del sandbox Variables entre pasos de run_python, detección de columnas duplicadas, informes PDF / slides.
  9. Cuentas y proyectos Auth, trabajo en equipo, historial de sesiones y programación de corridas. Las sesiones siguen en memoria.
  10. Explicabilidad Importancia de variables / SHAP, diccionario de columnas y un modo oscuro de producción (Observatorio es solo propuesta).
